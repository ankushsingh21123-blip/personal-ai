# Piplet Deep Audit — 18 Nov 2026

**Scope:** `~/workspace/personal-ai/`, HEAD commit `e23a63a` (143/143 tests, 35/35 built-in security checks, 24 tools).
**Method:** 5 parallel read-only reviewers — (1) backend/database/HTTP, (2) frontend/wiring, (3) security, (4) computer-use capability gap vs Codex/Claude Code/Antigravity, (5) stability/crash paths. Local runs only: throwaway DBs/workspaces, local Ollama, provider stubs. No code was edited, committed, or pushed by this audit. $0 spent. No live keys, no sign-ins, no one contacted, nothing external exploited.
**Caveat — moving target:** cycle 2 (eval harness + audit log) and cycle-3 skills code were being edited into the working tree throughout the audit. Reviewers anchored to HEAD via `git show HEAD:…` where the tree differed; line numbers below are approximate against the tree each reviewer read and are marked HEAD vs working-tree where it matters. Findings about cycle-2/3 code are flagged as follow-ups, not HEAD findings.

## Verdict

**No Critical findings.** The core is genuinely solid where it is proven: request handling survived ~300 adverse probes, auth is enforced with timing-safe compare, all SQL is parameterised, the deny-first tool model holds, and the 2-turn chat cap works. But the audit found **16 High** findings, including two real security holes (a secrets leak and a self-modification path to arbitrary code execution), a server-freezing SQLite defect, and six frontend defects where the UI silently destroys user data or feedback. The honest capability picture: Piplet's proven core is a loopback chat app with a deny-first file/note/fetch toolset plus queue/routine/replay substrate; **every real-screen, phone, messaging, vision, and second-machine path is code + mocked tests only** — nothing there has ever run live.

### Ranked gap list (what closes each gap)

1. **No proven end-to-end computer-use loop** (blocker). Fix zoom wiring + pass step history into grounding, add screenshot scaling, run golden tasks on the Windows laptop with a real key, fix the untested PowerShell/SendKeys issues that surface. ~1–2 weeks laptop iteration. Deps: laptop, vision key.
2. **No OS-level sandboxing.** Codex sandboxes by default (Seatbelt/bubblewrap+seccomp/Windows native); Claude Code has an opt-in Bash sandbox; Antigravity scopes workspaces + gates tools + proxies. Close with: disposable VM/container boundary for untrusted execution, sandboxed Chromium, per-platform shell profiles. ~2–4 weeks for one platform; full parity is multi-month. Deps: virtualization, plus a product decision (guest desktop vs live desktop).
3. **Single capped turn — no planning, sessions, subagents, context management.** Comparators run persistent resumable sessions with subagent delegation, workflows, compaction. Close with: session store + resume, planner step, sequential execution in all paths, bounded subagents, context budgeting/compaction, streaming. ~3–5 weeks (+1–2 for compaction). Deps: capable planning model (VM 0.6b provably cannot do structured tool use).

5. **Browser is single-shot and stateless.** Close with: persistent browser contexts, a snapshot/DOM + vision agent loop, recordings as verification artifacts, evals on owned sites. ~2–4 weeks. Deps: laptop, vision model.
6. **Phone: no loop, no grounding, pixels only, Android-only.** (Gap vs Piplet's own goal, not a comparator feature — none of the three does phone control.) Close with: `screenLoop` + ADB adapter, `dump`-XML element-first path, golden tasks on a real device. ~2–3 weeks. Deps: Android phone + ADB + vision key. iOS stays out of scope.
7. **Prompt-JSON grounding vs model-native toolsets.** Anthropic's 17-member toolset (batches, injection classifiers) and OpenAI's structured computer tool. Close with: native-toolset path(s) through the same validators, batch handling, verification step, measured grounding evals. ~2–3 weeks for one provider. Deps: keys/model access (tension with $0 — budget explicitly).

**Not gaps (deliberate refusals — do not "close" without changing the safety model):** browser submit/send, password/OTP typing or reading, UAC clicks, payments, account creation, uploads, in-page JS, arbitrary shell, bulk messaging, CAPTCHA bypass.
